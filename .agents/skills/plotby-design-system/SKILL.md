# Plotby Design System

Centralize colors, spacing, typography, radius, and motion tokens. Use shared `AppText`, `AppButton`, and `AppInput` rather than screen-specific styling. Brand colors are background `#101310`, surface `#1C211C`, elevated `#282E28`, primary `#C9FF32`, yellow `#F6C92B`, text `#F7F9F5`, muted `#A7B0A5`, border `#343B34`, and error `#FF6666`.

Build reusable primitives and form controls with disabled, pressed, loading, focus, validation, accessibility, safe-area, and reduced-motion support. `AppButton` supports primary, secondary, outline, ghost, and danger variants plus sm/md/lg sizes, icons, loading, disabled, fullWidth, and onPress. `AppInput` supports default, icon, and icon-unit variants with labels, units, errors, helper text, required state, refs, controlled values, and numeric keyboard behavior. Demonstrate shared components in a showcase and avoid arbitrary or duplicated styling.
